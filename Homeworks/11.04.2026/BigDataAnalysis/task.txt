Тема: «Анализ гигантских данных».
Инструкция по генерации файла:
using (var sw = new StreamWriter("bigdata.txt")) {
for (int i = 0; i < 50_000_000; i++)
sw.WriteLine("Data line with some A symbols and other chars");
}
Задача:
1. Прочитать этот файл через FileStream.
2. Посчитать количество символов 'A' (байт 65 в UTF-8).
3. Ограничение: Использовать буфер byte[65536]. Программа не должна потреблять более 50 МБ RAM.
4. Вывести время выполнения (использовать Stopwatch)

Учти, что ты должен записать не шаблонный текст, а рандомить его и записывать в txt.
