## Задание 1. Универсальное хранилище данных (Generics + Delegates)

Реализуйте класс `SimpleStorage<T>`, который позволяет хранить объекты и выполнять по ним поиск с использованием делегатов.

```csharp
public class SimpleStorage<T>
{
    private List<T> _data = new List<T>();

    public void Add(T item) { ... }

    public List<T> FindAll(Func<T, bool> predicate)
    {
        // Вернуть элементы, соответствующие условию
    }
}
```

### Требования:

1. Хранить данные в приватном списке.
2. Метод `FindAll` принимает делегат `Func<T, bool>` (предикат) и возвращает список всех элементов, для которых предикат вернул `true`.
3. Реализуйте метод `RemoveAll(Func<T, bool> predicate)`, который удаляет из коллекции все элементы, попадающие под условие, и возвращает количество удаленных элементов.

В Main:
1. Создайте класс `Employee` с полями `Name`, `Age` и `Department`.
2. Добавьте в хранилище 5 сотрудников.
3. Используя `FindAll`, получите список сотрудников старше 30 лет и выведите их.

## Задание 2. Датчик мониторинга показателей (Events)

Реализуйте систему оповещения о критических изменениях показаний датчика.

```csharp
public class SensorEventArgs : EventArgs
{
    public double OldValue { get; set; }
    public double NewValue { get; set; }
    public double PercentChange { get; set; }
}

public class Sensor
{
    private double _currentValue;
    public event EventHandler<SensorEventArgs> Alert;

    public void SetValue(double newValue) { ... }
}
```

### Требования:

1. При вызове `SetValue` вычислять разницу между старым и новым значением.
2. Если новое значение отличается от старого более чем на **10%**, вызвать событие `Alert`.
3. В аргументах события передать старое значение, новое значение и вычисленный процент изменения.

В Main:
1. Создайте датчик температуры.
2. Подпишитесь на событие `Alert`.
3. В обработчике выводите сообщение: "Внимание! Изменение на [Percent]%! Старое значение: [Old], Новое: [New]".
4. Измените значение датчика так, чтобы сработало оповещение.

## Задание 3. Анализ лог-файлов (IO + LINQ)

Дан текстовый файл `app.log`. Каждая строка имеет формат: `[TIMESTAMP] [LEVEL] MESSAGE` (например: `2023-10-27 10:15:00 ERROR Database connection failed`).

### Требования:

1. Прочитать файл логов.
2. С помощью LINQ:
    - Извлечь все строки с уровнем "ERROR". Where
    - Подсчитать общее количество ошибок. Count
    - Вывести последние 5 уникальных сообщений об ошибках. Take, Skip
3. Результат анализа сохранить в `error_report.txt`.
